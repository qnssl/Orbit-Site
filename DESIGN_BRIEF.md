# DESIGN_BRIEF — Orbit

- **Тема:** интерактивная учебная 3D-обсерватория Солнечной системы (инструмент, не лендинг и не портфолио-страница).
- **Структура:** один экран-инструмент без прокрутки и без роутера. Слои: 3D-сцена на весь экран, верхняя панель, список тел, панель объекта, нижняя панель времени, диалоги «О модели» и «Справка».
- **Первый экран:** общий вид системы сверху под углом, Солнце в центре, тонкие орбиты, подписи тел. Сразу рабочий интерфейс.
- **Навигация:** выбор тела кликом в сцене или в HTML-списке (на мобильном — горизонтальная лента под верхней панелью). Камера следует за выбранным телом; «Общий вид» и клавиша R возвращают обзор.
- **Палитра:** почти чёрный фон (#04060a), холодные серые линии, один акцент — бледно-бирюзовый (#9fd8cf) только для активного выбора. Естественные цвета у планет.
- **Типографика:** системный гротеск для текста, моноширинный для чисел, подписей и счётчика; мелкие подписи капителью с трекингом.
- **Графика:** реальная 3D-сцена (сферы, кольца Сатурна, звёздное поле); процедурные canvas-текстуры (суша и океан Земли, полосы Юпитера, красноватый Марс), без внешних изображений.
- **Анимация:** спокойное орбитальное движение по времени между кадрами, плавное прерываемое движение камеры; при prefers-reduced-motion движение не стартует само, камера переключается мгновенно.
- **Главное взаимодействие:** выбор тела — камера плавно подлетает и сопровождает его по орбите; пользователь может прервать жестом. Управление скоростью времени и паузой.
- **Мобильная версия:** данные объекта в нижней панели высотой до 40% экрана, управление временем компактными рядами; сцена упрощена (меньше звёзд и полигонов, ниже pixel ratio).
- **Fallback:** при отсутствии WebGL — сообщение, 2D-схема орбит и тот же список тел с панелью данных.
